## Classification rules

**VERIFIED FIXED:** actual reviewed integrated implementation closes the reported path and successful executed security tests prove the acceptance property. **SOURCE MITIGATION ONLY:** relevant checks are present in the combined code, but actual required tests have not passed on that exact head. **NOT TESTED:** no relevant runtime evidence, including historical or fixture-only assertions. **OPEN:** fault or missing capability persists, source design incomplete, or a release gate actually fails. A status such as "source mitigation" never implies an exploit was reproduced or that the entire finding is closed.
